## File Conventions
- **Naming**: PascalCase for classes (`ShopeeProductExtractor`), camelCase for functions/variables
- **Exports**: Named exports only; barrel files (`index.ts`) re-export public API
- **One class per file**: Single responsibility; file name matches class name
- **No default exports**: Except React components in `side-panel/`

## Module Boundaries (Allowed Imports)
| Module | Can Import From |
|--------|-----------------|
| `core/` | Nothing (leaf) |
| `platform/` | `core/` |
| `features/shopee/` | `core/`, `platform/` |
| `features/sixteen-eight-eight/` | `core/`, `platform/` |
| `features/side-panel/` | `core/`, `platform/` |
| `entry-points/` | `features/*`, `platform/`, `core/` |

**Forbidden**: `features/shopee/` ↔ `features/sixteen-eight-eight/` cross-imports; `features/*` importing `entry-points/`

## Data Flow
```
Shopee product page (content.ts)
  → ShopeeProductExtractor.extract() → ShopeeProduct
  → ButtonInjector.inject() → "Tìm trên 1688" button
  → User clicks → extractor.getMainImageBlob() → Blob
  → platform.messaging.sendMessage({ type: 'SEARCH_1688', payload: { imageBlob, sourceUrl } })
  
Background SW (background.ts)
  → onMessage → SixteenEightEightApiClient.search(imageBlob)
  → POST to 1688 endpoint (multipart/form-data)
  → ResultParser.parse(html) → SixteenEightEightResult[]
  → platform.messaging.sendResponse({ type: 'SEARCH_1688_RESULT', payload: { results } })
  
Side Panel (sidepanel.tsx)
  → onMessage → SidePanelState.transition('loading' → 'results'|'error'|'empty')
  → ResultsTable renders SixteenEightEightResult[]
  → User clicks "Mở trên 1688" → platform.tabs.create({ url: result.productUrl })
```

## Chrome Extension Specifics
- **Manifest V3**: Generated by Plasmo from `package.json` + `plasmo.config.json`
- **Host permissions**: `*://*.shopee.vn/*`, `*://*.shopee.com.vn/*`, `*://*.1688.com/*`
- **Background**: Service worker (`background.ts`), event-driven, 30s idle timeout
- **Content script**: `content.ts`, `matches: ["*://*.shopee.vn/*", "*://*.shopee.com.vn/*"]`, `run_at: "document_idle"`
- **Side panel**: `sidepanel.tsx`, registered via `chrome.sidePanel.setOptions({ path: 'sidepanel.html' })`
- **Messaging**: `chrome.runtime.sendMessage` / `chrome.runtime.onMessage` with Promise wrapper (30s timeout)
- **Rate limit**: 1 request per 2 seconds enforced in `SixteenEightEightApiClient`
